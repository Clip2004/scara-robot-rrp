# Instrumentacion (fuente web)

Fuente principal: https://alejoblandon22.wixsite.com/robot-scara/copia-de-fabricaci%C3%B3n
Fecha de integracion: 2026-04-06

## Componentes de instrumentacion

El sitio describe una instrumentacion enfocada en seguridad de movimiento y retroalimentacion:

- 4 finales de carrera para limites mecanicos
- 2 motores Pololu como base de actuacion de articulaciones
- Sensado por encoder para estimacion de posicion y velocidad

## Objetivo de la instrumentacion

La seleccion de elementos busca operacion autonoma confiable, deteccion de limites fisicos y continuidad de control durante ejecucion de trayectorias.

## Evidencia multimedia en origen

La pagina presenta una galeria de elementos y una tabla de componentes. Parte de esa evidencia visual se integra en media/images/web para respaldo local del repositorio.
