## Objetivo de manufactura

La seccion de manufactura describe el enfoque para construir un robot SCARA orientado a aplicaciones de soldadura. El criterio de diseno prioriza tres variables: alcance geometrico, precision del efector final y comportamiento velocidad/posicion durante la operacion.

## Enfoque de construccion

Se reporta una estrategia de fabricacion enfocada en viabilidad academica y reproducibilidad de laboratorio. La estructura mecanica fue planteada para facilitar ensamblaje, mantenimiento y pruebas de trayectorias sobre piezas de practica.

## Relacion con la aplicacion

La manufactura se conecta con el caso de uso de soldadura MIG/TIG: un diseno mecanico estable reduce error acumulado, mejora repetibilidad y simplifica la etapa de control.
