## Logros reportados

Para la entrega final se reporta cumplimiento de objetivos del proyecto integrador: robot SCARA 3 GDL con rutina home, trayectoria lineal, trayectoria semicircular y movimiento a puntos en el workspace.

## Conclusiones tecnicas destacadas

- Un buen diseno mecanico simplifica control y mejora precision de posicion.
- El ruido en lectura de encoder fue un reto importante para calidad de medicion.
- MicroPython cumple para prototipo academico, pero no es ideal para requisitos de temporizacion estricta.
- El trabajo interdisciplinario fue clave para cerrar el proyecto con resultados funcionales.

## Recomendaciones futuras

- Migrar firmware a C/C++ para mayor rendimiento temporal.
- Reemplazar o complementar filtro de media movil con filtrado digital pasa-bajas.
- Usar mayor relacion de transmision para mejorar resolucion de posicion.
